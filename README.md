Student Help Desk is a web-based application developed to manage and resolve
student queries efficiently. It allows students to raise support tickets and
enables faculty and administrators to track and resolve those queries in an
organized manner.

ThisThis project reduces manual communication and helps maintain proper records
of student issues related to software training and academics.
Technologies Used
- Frontend: HTML, CSS
- Backend: PHP
- Database: MySQL
- Server: WAMP Server
User Roles
- Admin: Manages users and monitors all queries
- Faculty: Views and resolves student queries
- Student: Submits and tracks support requests
Features
- Student login and query submission
- Faculty login and query resolution
- Admin login and system monitoring
- Simple and user-friendly interface
